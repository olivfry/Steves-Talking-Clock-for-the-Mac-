## Voice packs

Voice packs are not included with this project (other than the default voice). The format specification
(concatenation.txt) belongs to Stephen Clower. If you distribute voice packs
derived from or compatible with the original application, please ensure you
have the right to redistribute those recordings. The voice packs that are available on the Windows version should be compatible for the Mac version too. If you experience any issues, please open an issue. The official voice packs can be found at https://clock.steve-audio.net/voices/.

## Default voice

The `Default` voice folder is bundled with the app for immediate out-of-the-box
use. It was synthesised from a macOS system voice (Mac Alex) using
`/usr/bin/say`. You can replace or delete it from the voices folder at any time
using **Open Voices Folder** in the app.
