This file contains a listing of all the files required for every concatenation method for the clock. Files with an asterisk (*) next to them are optional, but any other files are mandatory. When necessary, there will be comments beside a wave file whose function must be explained. The program scans for certain files to identify the type of concatenation being used, so please do not drop your new voice into the clock's folder until all files have been created. Note: because scrolling through this document could become tedious, each new method has three plus signs (+++) preceeding it.
